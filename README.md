## Подготовка к запуску

### Установка зависимостей

Для установки зависимостей запустите из текущей директории

```
./scripts/setup.sh
```

Если используется не linux, то используйте любую llm для того, чтобы понять что надо делать

### настройка моделей

Откройте файл [config.py](backend-fastAPI/config.py) и задайте переменным `BASE_MODEL_URL`, `API_KEY`, `LLM_MODEL`, `EMBEDDING_MODEL` свои значения. По умолчанию заданы такие значения, чтобы модели запускались локально, через LM Studio.

### наполнение базы документами

> [!NOTE] 
> Перед этим этапом убедитесь, что модель для векторизации (н.р. nomic-embed-text-v1.5 запущенная через lm-studio) доступна.

Перейдите в директорию [backend-fastAPI](backend-fastAPI) и запустите

```
source venv/bin/activate
python ingest.py /путь/к/ресурсам/
```

## Запуск проекта

> [!NOTE] 
> Перед этим этапом убедитесь, что модель для векторизации и языкавая модель доступны.

> [!NOTE] 
> На данном этапе проект не предусмотрен для запуска в продакшн, тестирование запуска проводилось только в отладочном режиме.

Откройте в одном терминале директорию [backend-fastAPI](backend-fastAPI) и запустите

```
source venv/bin/activate
python main.py
```

Откройте в другом терминале директорию [web-ui](web-ui) и запустите

```
npm run dev
```

Откройте в браузере страницу `http://localhost:3000` и мучайтесь в попытках добиться приемлемого ответа от этого куска кода.
